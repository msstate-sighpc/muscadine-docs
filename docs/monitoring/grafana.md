# Grafana Dashboard

```{figure} ../_static/figures/monitoring/grafana-screenshot.png
```

Grafana is an amazing data visualiation dashboarding application that we use to see how the cluster is doing, how much usage there is, and if there are any potential problems. Grafana is avaliable through the [Open OnDemand]{../ood/index.md} platform located in the Clusters -> System Status page.
