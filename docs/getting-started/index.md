# Getting Started

This section walks you through everything needed to go from brand-new user to running jobs on Muscadine: requesting an ARC account, setting it up, and connecting to the cluster. Along the way you'll learn where your data lives on Muscadine's storage, the Linux and Slurm basics you'll use every day, and the supported ways to transfer data on and off the cluster.
